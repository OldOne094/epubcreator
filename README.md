# 📗 EPubCreator

مصنّع كتب **EPUB** لسطح المكتب، مكتوب بـ **Python + PySide6** ويستهدف **Windows**،
بدعم عربي احترافي كامل: محرر فصول، بيانات وصفية، تنسيق، أغلفة، معاينة، وتصدير
مطابق لمواصفات **EPUB3** (مع دعم استرجاعي لـ **EPUB2**).

> الشفرة مفتوحة ومُختبَرة؛ الهدف إنتاج كتب إلكترونية عربية جاهزة بواجهة
> بسيطة دون تقنيات معقدة.

---

## ✨ المزايا

- **استيراد متعدد الصيغ**: `TXT` · `Markdown` · `HTML` · `DOCX` · `RTF` — عبر الاختيار أو `Drag & Drop`.
- **تعرّف تلقائي على الفصول** (عناوين عربية/إنجليزية) ثم تقسيم الكتاب إلى فصول قابلة للتحرير.
- **محرر فصول** بشجرة تنقّل، يحرّر كل فصل على حدة.
- **بيانات وصفية (Metadata)**: العنوان، المؤلّف، المترجم، الناشر، الوصف، الكلمات المفتاحية،
  اللغة، ISBN، السلسلة، الحقوق، الغلاف — مع تحقق إلزامي من الحد الأدنى.
- **تنسيق احترافي عربي متعدد الطبقات**: يحافظ على أسطر الكتاب دون دمجها في فقرة واحدة
  (سطر فارغ = فقرة جديدة، أسطر قصيرة/شعر/قوائم تُحفظ مستقلة، والنص الملفوف يُدمج ذكيًّا).
- **قوالب جاهزة (5)**: رواية كلاسيكية · شعر · كلاسيكي داكن · عصري · أطفال + **CSS مخصص**.
- **تنسيق الفقرة**: المحاذاة، ارتفاع السطر، الفراغات، إزاحة السطر الأول، الحجم، الهوامش، اللون.
- **الغلاف**: صورة مستخدم (تعديل مقاس/ضغط) أو **توليد تلقائي** بألوان قالبك وخطوطه، مع
  **تشكيل عربي متصل** للعناوين (بلا أحرف مقطّعة عبر خوارزمية تشكيل مضمّنة).
- **معاينة حيّة** للفصول بتهيئة RTL قبل التصدير.
- **تصدير EPUB2/EPUB3** في خيط خلفي، مع شريط تقدم، بدون تجميد الواجهة.
- **ثيمات واجهة**: فاتح / داكن.
- **تسجيل أحداث** غير حاجز بصيغة JSON Lines عبر قوائم/مستمعات.

## 🛠️ التقنيات (Tech Stack)

| الطبقة      | التقنية                              |
|-------------|--------------------------------------|
| اللغة       | Python 3.11+                         |
| الواجهة     | PySide6 (Qt) — QTextBrowser للمعاينة |
| بناء EPUB   | مولّد داخلي خفيف `zipfile` + `lxml`  |
| استيراد DOCX| `python-docx`                        |
| استيراد RTF | `striprtf`                           |
| استيراد MD  | `markdown-it-py`                     |
| صور / أغلفة | `Pillow` + `arabic_reshaper` + `python-bidi` |
| المسارات    | `platformdirs`                       |
| التعبئة     | PyInstaller                          |
| الاختبار    | pytest                               |

> بلا تبعيّات ثقيلة: لا `EbookLib` (ترخيص AGPL)، ولا WebEngine ضمن الحزمة
> (محرّك Chromium اختياري وضخم الحجم خارج نطاق الحزمة).

## 📂 بنية المشروع

```
epubcreator/
├─ app/
│  ├─ main.py            # إدخال التطبيق
│  ├─ settings.py        # config.json (platformdirs) + تسجيل
│  ├─ models.py          # dataclasses: Metadata, Chapter, EpubOptions, Book
│  ├─ state.py           # BookState (QObject) — إشارات حالة الكتاب
│  ├─ workers.py         # ImportJob / ExportJob (QThreadPool)
│  ├─ core/
│  │  ├─ importers.py    # txt/docx/rtf/html/md → Book
│  │  ├─ clean.py        # تنظيف عربي + كشف الفصول
│  │  ├─ format.py       # تنسيق فقرات عربي متعدد الطبقات (حصانة الأسطر)
│  │  ├─ epub.py         # مولّد EPUB3/EPUB2 + CSS/OPF/nav
│  │  ├─ covergen.py     # الغلاف (Pillow + تشكيل عربي) + صورة المستخدم
│  │  ├─ templates.py    # 5 قوالب CSS
│  │  └─ validate.py     # تحقق XHTML/OPF/داخلي
│  └─ ui/
│     ├─ main_window.py  # نافذة + شريط جانبي + رأس + سحب وإفلات + ربط الصفحات
│     ├─ sidebar.py      # تنقّل جانبي (سير العمل) + تبديل الثيم
│     ├─ home_page.py    # رئيسية: نظرة عامة + حالة البداية
│     ├─ pages.py        # محرر الفصول (إضافة/حذف/ترتيب) + البيانات الوصفية
│     ├─ style_page.py   # قوالب + خطوط + تنسيق فقرة + CSS مخصص
│     ├─ cover_page.py   # غلاف: صورة/توليد تلقائي + معاينة
│     ├─ preview.py      # معاينة QTextBrowser بنفس CSS التصدير
│     ├─ export_page.py  # تصدير EPUB2/3 + تقرير تحقق
│     ├─ widgets.py      # مكوّنات مشتركة (بطاقات/عناوين)
│     ├─ dialogs.py      # أخطاء / تقدم
│     └─ themes.py       # ثيمات فاتح/داكن (QSS بتوكنات ألوان)
├─ tests/               # pytest (importers, clean, format, epub, cover, UI)
├─ dist/                # الحزمة النهائية (EPubCreator.exe)
└─ epubcreator.spec     # مخطط PyInstaller (onefile)
```

## ▶️ التشغيل من المصدر

> يتطلّع **Python 3.11** أو أحدث.

```bash
# 1. بيئة افتراضية
python -m venv .venv
.\.venv\Scripts\activate      # Windows

# 2. تثبيت المتطلبات
pip install -r requirements.txt

# 3. التشغيل
python -m app.main
```

---

## 🧪 الاختبارات

```bash
.\.venv\Scripts\python -m pytest tests -q
```

تغطية: استيراد، تنظيف/تشفير عربي، تنسيق الفقرات، مولّد EPUB، الغلاف (تشكيل
العربية وألوان القالب)، المعاينة، الواجهة (PySide6 offscreen)، والتتحقق الخارجي.

## 🔨 بناء الحزمة القابلة للتشغيل (EXE)

```bash
.\.venv\Scripts\pyinstaller epubcreator.spec --noconfirm --clean
```

الناتج: **`dist\EPubCreator.exe`** (حزمة واحدة، ~57MB، بدون نافذة طرفية).
يستثني المخطّط وحدات Qt الثقيلة (QtWebEngine…) للتحكم بالحجم، ويُضمّن تبعيّات
الغلاف (`arabic_reshaper`، `python-bidi`) في الحزمة.

> أغلق أي نسخة قيد التشغيل قبل إعادة البناء حتى لا يُحصم قفل حارس `dist` أثناء
> استبدال الملف.

## 🚀 سير الاستخدام

1. **الرئيسية**: استورد ملفات (أو اسحبها وأفلتها في النافذة) → يُكشف النوع ويُبنى الكتاب تلقائيًّا.
2. **المحرر**: عدّل الفصول؛ أضف/احذف/أعد ترتيبها؛ كل فصل اسمه ونصّه. تتحدث المعاينة حيًّا.
3. **البيانات**: أكمل العنوان (إلزامي) والبيانات الوصفية (مقسمة إلى أساسية/إضافية).
4. **التنسيق والقالب**: اختر من 5 قوالب جاهزة أو CSS مخصصًا واضبط الخطوط والفقرات.
5. **الغلاف**: صورة أو توليد تلقائي (يتبع ألوان قالبك وخطوطه) مع معاينة فورية.
6. **المعاينة**: عرض حي للكتاب أو فصل بنفس CSS التصدير (RTL/LTR).
7. **التصدير**: اختر EPUB3/EPUB2 والوجهة ثم صدّر؛ يعرض التطبيق تقرير تحقق بعد الانتهاء.
